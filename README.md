# Visual Interaction Design Learning

一个以「风格 → 组件 → 样式」为核心信息架构的视觉交互设计学习系统。

## 项目目标

- 建立由易到难、可持续扩展的视觉交互设计知识树。
- 区分视觉风格（Visual Style）、设计系统（Design System）、布局模式（Layout Pattern）、媒介/交互形态（Interaction Medium）。
- 将按钮、输入框、卡片、导航、模态框、列表、表格、图表、反馈、动效等组件映射到不同设计风格。
- 将颜色、字体、间距、圆角、阴影、边框、图标、布局、状态、动效、响应式与无障碍等样式 Token 系统化。
- 最终交付可直接浏览的 HTML 学习网页，并配套原创视觉示例。

## 核心信息架构

```text
风格 Style
└── 组件 Component
    └── 样式 / Token / State / Motion
```

## 分支策略

- `main`：稳定、可交付版本。
- `develop`：研究成果与网页功能集成。
- `feature/*`：较大的独立功能或课程分支。
- 里程碑完成后通过 Pull Request 从 `develop` 合并到 `main`。
